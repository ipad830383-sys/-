# 꿈틀꿈틀 실시간 모의주식 - 서버형 프로젝트

## 실행
- Node.js 18 이상 필요
- 프로젝트 폴더에서 `npm install`
- `npm start`
- 브라우저에서 `http://localhost:3000`

## 기능
- 참가자별 가상자금 100만원
- 모든 참가자에게 동일한 주가 실시간 전송
- 매수/매도
- 실시간 수익률 및 순위
- 게임 시작/종료/초기화
- 게임 중 7분(420초)마다 전체 종목 가격이 동시에 변동

## 여러 기기에서 접속
같은 Wi-Fi에서 서버를 실행한 컴퓨터의 내부 IP를 확인한 뒤 다른 기기에서 `http://서버컴퓨터IP:3000`으로 접속합니다.
인터넷 공개는 Render/Railway 등의 Node.js 호스팅에 배포하면 됩니다.

주의: 현재 관리자 버튼은 비밀번호 인증이 없는 데모 버전입니다. 공개 배포 전 관리자 인증을 추가하는 것을 권장합니다.
